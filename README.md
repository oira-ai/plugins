# Oira plugins

Coding-agent integrations for [Oira-Oira](https://oira-oira.com).
Oira helps a team keep track of its work from the coding it already does.

This repository is **private preparation only**. Plugin publishing is paused
until the separate package review and update are complete.

There are no installable plugins, marketplace manifests, releases, directory
submissions or publishing workflows here yet. Do not use this repository as an
installation source. Existing published installations remain on their current
source until the reviewed migration is released.

Package sources and the export tool live in
[oira-ai/platform](https://github.com/oira-ai/platform/tree/master/integrations/coding_agents).
The future release will contain only the reviewed production packages;
development packages and private platform files must never be exported.
